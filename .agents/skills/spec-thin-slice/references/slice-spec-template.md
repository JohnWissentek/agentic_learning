# 垂直薄切片规格书与「5 分钟中文验收矩阵」标准模板

在启动新项目或大模块时，复制以下轻量级结构（避免长篇瀑布流废话，全文控制在 80～120 行以内）：

```markdown
# <功能/项目名称> 契约与垂直薄切片实施蓝图

## 1. 一句话目标与本期不做清单 (Scope & Non-Goals)
- **核心交付目标**：<一句话说清谁在什么场景下解决什么核心问题>
- **本期坚决不做（防过度设计）**：
  - 不做 <外延功能 1>
  - 不做 <外延功能 2>

## 2. 🔴 红区物理隔离文件约定（人类 100% 精读区，合计 <= 300 行）
- `src/<pkg>/schemas.py`：核心枚举、入参出参 Pydantic 模型与安全默认值
- `src/<pkg>/prompts/system_prompts.py`：全系统唯一集中存放的大模型提示词
- `src/<pkg>/guard.py`：白名单校验、人类确认令牌验签、脱敏与关键数字核验

## 3. 垂直薄切片推进路线与中文验收矩阵

### Slice 0：红区契约底座与空骨架（不写业务实现）
- **交付文件**：`schemas.py`、`system_prompts.py`、`guard.py`、`config.py`
- **放行标准**：强类型检查通过，人类架构师逐行确认字段默认值与提示词红线无误。

### Slice 1：<最小端到端主干名称，如：单人白名单与 0 模型快捷指令闭环>（预计 ~200 行）
- **端到端范围**：入口接收 → 白名单拦截 → 快捷口令解析 → 真实 SQLite 落盘与撤销快照
- **中文验收矩阵（供 `blind-test-author` 生成红灯测试）**：
  - **[正常 1]** 本人账号发送 `完成 #1` → 状态更新为 `done`，生成 24h 撤销快照，返回完成回执。
  - **[边界 1]** 发送不存在的编号 `完成 #999` → 不抛未捕获异常，友好提示编号不存在，库表 0 变更。
  - **[边界 2]** 同一 `msg_id` 网络抖动重复送达 2 次 → 第 2 次直接幂等跳过，不重复执行。
  - **[禁令 1]** 非白名单账号发送任何指令 → 入口静默丢弃，LLM 调用次数 == 0，库表 0 变更。
  - **[禁令 2]** 所有快捷口令路径 → LLM 网关调用次数必须严格 == 0。

### Slice 2：<下一根端到端薄片名称>（预计 ~250 行）
- **端到端范围**：...
- **中文验收矩阵**：
  - **[正常 1]** ...
  - **[边界 1]** ...
  - **[禁令 1]** ...
```
