# 03｜逐行白话伪代码对照手册（纯 Python 版 + LangGraph 版）

> **怎么读这份手册？**
> 左边是真实可运行的程序在干什么，右边是**完全不带编程术语的白话伪代码**。建议先看**第一部分（纯 Python 版）**彻底打破“神秘感”，再看**第二部分（LangGraph 版）**理解工业框架是如何把同一套原理升级为“专业球台”的。

## 第一部分：纯 Python 原理版（对应 `01_pure_python_pingpong.py`）

### 白话伪代码全流程

```text
【准备工具箱】（真实能干活的手脚，大模型碰不到，全归本地代码）
  工具1 网页搜索(搜索词):
      联网去查资料，把查到的文字原样返回
  工具2 计算器(算式):
      用安全算术引擎算出精确数字并返回

【准备大脑】（远程大模型，只能看白板、开点菜单或写答案）
  函数 唤醒大脑(白板全部记录):
      把白板记录 + 工具菜单说明书 一起发给大模型
      如果 大模型觉得信息不够:
          返回 { 思考过程, 点菜单: [工具名 + 参数], 最终答案: 空 }
      否则:
          返回 { 思考过程, 点菜单: 空, 最终答案: "给人类看的话" }

【启动打乒乓球循环】（外层好硬编码：只负责传球与数步数，绝不猜语义）
  函数 运行智能体(用户问题, 最大步数上限 = 5):
      初始化 共享白板 = [ 用户问题 ]

      从 第1回合 数到 第最大步数回合:
          1. 唤醒一次大脑(共享白板) -> 拿到 大脑本轮回复
          2. 把 大脑本轮回复 贴到 共享白板 末尾

          3. 【门卫安检】：看 大脑本轮回复 里有没有【点菜单】？
             如果 没有点菜单:
                 立刻跳出循环，把【最终答案】呈给用户！

          4. 【工具车间】：如果有点菜单，逐条真正执行：
             对 点菜单里的每一项(工具名, 参数):
                 尝试 调用 本地工具箱[工具名](参数) -> 拿到 真实结果
                 如果工具报错了:
                     不要崩溃！把 "工具报错原文" 当成 真实结果
                 把 真实结果 贴到 共享白板 末尾
          （自动回到循环开头，带着新结果再次唤醒大脑！）

      如果跑满最大步数还没结束:
          【熔断刹车】强行停止，提示人类介入，绝不无限死循环！
```

### 关键代码行 1:1 解读

| 真实代码位置 (`01_pure_python_pingpong.py`) | 这一段到底在干什么？（人话） | 属于大脑还是底盘？ |
| :--- | :--- | :---: |
| `tool_web_search`、`tool_calculator`（L29–51） | 真正能上网、能算账的手脚函数，大模型自己永远执行不了。 | 🛡️ 底盘（工具） |
| `TOOL_REGISTRY`（L55–58） | 车间花名册：把工具名字（如 `"calculator"`）对应到真正的函数。 | 🛡️ 底盘（工具） |
| `fake_llm_brain`（L66–105） | 模拟大脑：每次醒来只看白板，决定发 `tool_calls` 点菜单还是发最终答复。 | 🧠 大脑（LLM） |
| `for step in range(1, max_steps + 1):`（L118） | **循环转盘 + 步数熔断器**：最多允许来回打 5 拍，到顶强制刹车。 | 🛡️ 底盘（Loop） |
| `if not tool_calls: return reply["content"]`（L125–127） | **极简门卫**：完全不理解句子意思，只看有没有点菜单；没有就交卷。 | 🛡️ 底盘（Loop） |
| `try: result = TOOL_REGISTRY[fn_name](**fn_args)`（L134–138） | **工具车间 + 容错保护**：真执行工具；出错不崩，把报错原文贴回白板让大脑改。 | 🛡️ 底盘（Harness） |

## 第二部分：LangChain + LangGraph 工业版（对应 `02_langgraph_react_pingpong.py`）

你会发现，LangGraph 的底层逻辑和上面那段纯 Python **一模一样**，只是把每个动作标准化成了可存盘、可暂停、可画图的“房间与连线”。

### 白话伪代码全流程

```text
【第 1 步 · LangChain 制作标准工具菜单】
  用 @tool 标签包装 网页搜索(搜索词)      # 自动把中文说明转成大模型读得懂的说明书
  用 @tool 标签包装 计算器(算式)
  工具清单 = [网页搜索, 计算器]
  大脑模型 = 真实大模型.绑定工具菜单(工具清单)   # bind_tools：每次提问自动附带菜单

【第 2 步 · 定义共享白板（State）】
  白板结构 AgentState:
      messages:   消息列表（规则：add_messages = 永远往后追加，不覆盖旧记录）
      step_count: 已唤醒大脑的轮次（Harness 计步器）

【第 3 步 · 盖两个房间 + 放门卫 + 拉回头线（LangGraph 6 行搭台）】
  房间 A【大脑室 model_node】(当前白板):
      让 大脑模型 读一遍 当前白板.messages -> 得到 回复
      返回 { messages: [回复], step_count: 当前步数 + 1 }

  房间 B【自动工具车间 ToolNode(工具清单)】:
      （LangGraph 免费自带！不用手写分发代码）
      自动读取最后一条消息里的全部 tool_calls 点菜单
      自动调用对应工具（支持并行调用多个工具）
      自动把结果或报错包装成 ToolMessage 贴回白板

  门口【极简门卫 gatekeeper】(当前白板):
      查看白板最后一条消息：
      如果 (包含 tool_calls 点菜单) 且 (step_count < 最大步数上限):
          挥手放行 -> 去房间 B "tools"
      否则:
          打开出口 -> 去终点 END（交卷！）

  【画图连线】（核心 6 行）：
      1. 建图 StateGraph(AgentState)
      2. 加房间 A："model"
      3. 加房间 B："tools"
      4. 起点 START  ——→  房间 A "model"
      5. 房间 A "model"  ——(过门卫判断)——→  房间 B "tools" 或 终点 END
      6. 房间 B "tools"  ——(回头线)——→  房间 A "model"
      7. 编译成可运行状态机，并挂上【自动存盘器 MemorySaver】

【第 4 步 · 流式运行并直播每一拍】
  把 用户提问 写上白板，启动状态机（同时配上全局安全阀 recursion_limit）
  每当一个房间干完活，立刻打印这一拍的实时进展，直到走入终点 END！
```

### 关键代码行 1:1 解读

| 真实代码位置 (`02_langgraph_react_pingpong.py`) | 这一句在框架里起什么作用？（人话） | 为什么比手写 `while` 更强？ |
| :--- | :--- | :--- |
| `@tool`（L45、L58） | LangChain 工具装饰器：把函数名、参数类型、中文说明自动打包成标准 JSON Schema 菜单。 | 换任何大模型（GPT/Gemini/Qwen）都能直接看懂，不用手拼 Prompt 格式。 |
| `Annotated[list[AnyMessage], add_messages]`（L84） | 共享白板“只追加、不覆盖”规则（State Reducer）。 | 多节点并发写入时不会把前面轮次的记录意外擦掉。 |
| `.bind_tools(TOOLS)`（L137） | 把工具清单绑定到大模型接口上。 | 模型在底层原生支持输出结构化 `tool_calls`，准确率远高于纯文字 Prompt。 |
| `ToolNode(TOOLS)`（L162） | LangGraph 内置自动工具车间。 | 自动解析多工具并发点单、自动捕获异常回传给模型，省去全部样板代码。 |
| `builder.add_conditional_edges("model", gatekeeper, ...)`（L169–173） | 门卫条件边：把“要不要继续循环”变成显式可审计的状态机分支。 | 一眼就能画成标准 UML 2.5 状态机图，绝不会藏在深层嵌套代码里失控。 |
| `builder.add_edge("tools", "model")`（L174） | 回头线：工具执行完永远自动回到大脑室继续判断。 | 构成完整的 `model ↔ tools` 乒乓球闭环。 |
| `checkpointer=MemorySaver()`（L177） | 检查点存盘器（生产环境换 SQLite/Postgres）。 | **Harness 核武器**：每走一步自动存盘，支持高危操作前暂停等人类审批（`interrupt`）或一键时光倒流回滚。 |
