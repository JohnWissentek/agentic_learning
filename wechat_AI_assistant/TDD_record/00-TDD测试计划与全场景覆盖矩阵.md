## 二、 极端异常与故障注入场景全覆盖矩阵

| 编号 | 故障/异常类型 | 触发方式 | 期望生产级韧性表现 |
| :--- | :--- | :--- | :--- |
| **E01** | 加密/损坏文档与 ZIP 炸弹 | 传入损坏 `.docx`/`.xlsx`/`.pdf`/`.zip`、超 30 文件、超 50MB、路径穿越 `../` | 0 崩溃，统一降级安全单页占位说明，绝不污染 FTS |
| **E02** | 企微回执超时 / 媒体下载抖动 | `send_app_push` 首条回执抛异常，或解析阶段瞬时异常 | 回执失败不丢消息；解析失败不烧毁 `MsgId` 去重表，重推可成功 |
| **E03** | 邮件域名配置损坏 / 推送失败 | `config/mail_domains.json` 语法损坏，或汇总推送微信失败 | 域名损坏时回退缓存或跳过且不前移水位；推送失败回滚本班新建确认卡、不标 seen、不前移水位 |
| **E04** | 数据库 JSON 脏字段 / FTS5 特殊符号 | `aliases_json` / `topic_tags_json` 损坏；用户输入含 SQLite FTS 特殊符号（如 `"`、`*`、`NEAR`） | 安全容错降级为空列表或 `LIKE` 检索，绝不阻断阶段二/三 |
| **E05** | 大模型超时、限流、畸形 JSON 或全挂 | 主模型报错切换备用模型；路由主备全挂；模型返回带 `<think>` 与尾逗号的脏 JSON；工具参数传非法日期 | 主备自动退避切换（上限 4 次）；路由全挂时死暗号仍可用；其余消息记录原话并安全回复 |
| **E06** | 异构审计连续 2 轮未通过（防死循环） | Critic 连续 2 轮返回 `passed=False` | 严格在第 2 轮跳出回环进入确认卡，且在卡片上显式印出「⚠️ 审计待人工复核点」 |
| **E07** | 阶段五 OneDrive 503 故障 | 确认落盘、打卡、撤销时 OneDrive 全接口抛异常 | 本地 SQLite 单事务照常成功提交，如实告知“已落盘，云端同步稍后补刷”，绝不谎报未落盘 |
| **E08** | 密钥泄漏与越权攻击 | 模型或工具返回意外拼入 API Key；非法企微签名；陌生外部号/非白名单邮件夹带提示词注入 | 输出闸门拦截并脱敏；非法签名 403；非白名单静默丢弃；邮件包裹 `[UNTRUSTED_EXTERNAL_DATA]` |
| **E09** | 边界输入与操作异常 | 纯空白消息、超长消息、重复确认同一张卡、超 24h 撤销、批量打卡混入不存在编号、Web 非法参数与过期 Cookie | 全部受控返回清晰提示或 4xx 状态码，零未捕获 500 崩溃、零脏数据写入 |
