## 二、 本次体检发现的 2 个关键官方限制（开工前重大排雷）

通过现场核查后台界面元素（#profile/wxPlugin 内无机器人勾选列表，点 添加应用 直接跳转创建自建应用 #apps/createApiApp）并对照企业微信后台直链官方帮助文档（doc_id=14802、21663、101463），确认存在两条必须在写代码前拍板的官方边界：

> [!IMPORTANT]
> 1. 「智能机器人（API 长连接）」无法进入「微信插件」，不能在绿色「个人微信」里 1 对 1 对话：
>    - 企业微信官方规定：“仅企业微信基础应用及自建应用可在微信插件中查看”（doc_id=14802）。
>    - 智能专区 → 智能机器人 仅能在蓝色「企业微信 App / 桌面客户端」的 通讯录 → 智能机器人 或 工作台 → 智能机器人 中进行企业内部单聊或内部群聊，不支持外部群/客户群，也不会出现在绿色个人微信的「我的企业及企业联系人」列表里。
> 2. 「智能机器人」长连接不支持「合并转发」聊天记录消息类型：
>    - 智能机器人长连接官方协议支持 文本（text）、图文混排（mixed）、引用消息（单聊/群聊）以及 图片（image）、语音转文字（voice）、文件（file）、视频（video）（仅单聊），暂不支持多条聊天的「合并转发」卡片（只能逐条转发或单条发）。
>    - 在整个企微合规体系中，唯一原生支持个人微信直接多选 「合并转发（merged_msg）」 并由服务端调用 sync_msg 完整拆出逐条发送人与原话的官方接口，是 应用管理 → 基础 → 微信客服 API。

> 📌 2026-11-17 最终拍板：采用 方案 B（绿色个人微信置顶「微信客服 API」接合并转发 + 「自建应用 / 微信插件」推每日简报），统一复用 https://assistant.fire-matrix.com 回调入口。

| 对比维度 | 方案 A：蓝色企微 App + 智能机器人长连接 | 方案 B（✅ 已定稿锁定）：「微信客服 API」+「自建应用/微信插件」双口协同 | 方案 C：仅「自建应用 + 微信插件」 |

## 四、 真实后台界面分步操作指南（中英文双语对照）

> 因为您当前后台默认显示为英文，以下每一步均同时标注 中文（English） 菜单原文，方便直接对照点击。

### 4.1 查看并复制已配好的「智能机器人」Bot ID 与 Secret（若选方案 A）
1. 登录 https://work.weixin.qq.com/wework_admin/frame#/apps 后，不要在中间主区找机器人，直接看最左侧竖向主导航：
   - 点击 智能专区（Intelligent Zone） → 智能机器人（Intelligent robot）。
2. 在顶部选项卡点击 机器人管理 → 企业创建，找到您建好的机器人，点击进入 智能机器人详情。
3. 点击页面右上角 编辑：
   - 核实顶部模式已处于 API 模式；
   - 核实 API 配置 下连接方式已选中 使用长连接；
   - 在 Bot ID（35 位）与 Secret（43 位）右侧分别点击 复制图标 写入服务器本地配置即可。切勿点击 Secret 旁的重置图标（重置会导致旧密钥立刻失效）。
4. 核实 使用模式 → 使用方式 保持 仅个人使用，点 保存（如未修改直接点返回）。

> 附：如何新建第二个 API 长连接机器人：入口在 智能专区（Intelligent Zone）→ 智能机器人（Intelligent robot）→ 创建 → 新建机器人 → 顶部右侧单选卡片 API 模式 → 连接方式选 使用长连接 → 保存后复制新的 Bot ID 与 Secret。

### 4.2 iPhone 实机适配：将「微信插件」升级为单一大入口（个人幕僚室 → AI工作助理）
> 实机关键结论（2026-11-17 iPhone 实测）：
> 1. 经 iPhone 微信实机测试，新版 iOS 微信将所有企业微信客服强行收入 客服消息 折叠盒子里且不支持单独置顶，同时「合并转发」选择器无法直接选中折叠盒内的客服号；
> 2. 与之相反，微信主聊天列表中的 个人幕僚室（微信插件入口）支持直接在 iPhone 左滑/长按置顶！因此我们已在 wecom_gateway.py 为自建应用补齐 文本、语音、图片、PDF/Excel、链接、位置 全模态解析与 8 秒静默聚合（多选后「逐条转发」即在 8 秒内拼成同一上下文统一分析）；
> 3. 原微信客服号已改名为 备用客服通道（保留 https://work.weixin.qq.com/kfid/kfc8f28468c25b71aab?enc_scene=ENC6AZ28iGA6GUZkxjMrQZubqemuCY1aXgBipaPgRCj8Pn6 作手机扫码备用，并仍受 owner_whitelist.txt 单人白名单保护）。

### 4.3 自建应用 AI工作助理 与 https://assistant.fire-matrix.com 统一驾驶舱
> 核查确认您已在 我的企业（My Company）→ 微信插件（WeChat Plugin） 完成个人微信 已关注，且已勾选 允许成员在微信插件中接收和回复聊天消息。

1. 名称与职责：自建应用 AI工作助理（AgentId=1000002）位于可置顶的 个人幕僚室（企业简称）内，现承担 100% 全能对话 + 早晚简报 + 6 位驾驶舱验证码推送。
2. 后台绑定状态：接收消息 API 回调 https://assistant.fire-matrix.com/api/wecom/app/callback（echostr 校验通过）、企业可信 IP、以及 Manage chat messages via API -> In-house development 接管 备用客服通道 均已完成。
3. Executive Work OS（monday.com 风格全英文驾驶舱）：已于 https://assistant.fire-matrix.com 正式上线，支持 Main Table 分组、Status/Priority/Domain 彩色弹出选择器、Timeline 与 Gantt 横向拖拽调期、Workload 负荷气泡与 Analytics 视图。
