## 一、 阿里云单机部署边界（什么跑在 ECS，什么存在世纪互联 OneDrive）

整套软件采用**「单机全包、网盘沉淀、零外部 ERP 依赖」**拓扑：

- **运行在阿里云 ECS `firematrix`（呼和浩特，2 核 4G，Ubuntu 24.04，详见本地 `env/.env.ecs`）上的组件**：
  1. **董事长助理智能体内核**（企微长连接 + 只读邮件拉取 + LangGraph 有界闭环 + 百炼三档模型调用）；
  2. **同进程内嵌式「董事长项目管理与工时分析驾驶舱 Web App」**（FastAPI + 静态 ECharts/甘特图前端）；
  3. **SQLite 结构化数据库与全文检索索引**（`app.db` 与 `checkpoints.db`，含所有任务、起止时间、净工时、项目状态和文档按页提取纯文本）。
  - *运行方式*：以独立非特权系统用户 `wxagent` 跑 `systemd` 单实例后台服务，与机上已有官网 `firematrix-web`（端口 3000）互不干扰。
- **主存于 Wissentek 世纪互联版企业 OneDrive 的内容**：
  - 全部原始转发文件与邮件附件（`00_原件收件箱/`）、自动命名的分类文档库（`01_项目归档`～`04_想法与行业参考`）以及自动渲染的四大 Markdown 清单（`00_我的四大清单/`）。
  - **60G 云盘永不爆满机制**：大附件上传 Wissentek 世纪互联校验完成后自动清理 ECS 本地临时缓存，ECS 只保留纯文本索引；与此同时，你的办公室与家里 Mac 原生自动同步全部分类原件。

## 二、 企业核心信息防外泄「六道硬防线」

| 防线 | 核心举措 |
| :--- | :--- |
| **1. 入口与组织隔离** | 采用企业微信「API 模式智能机器人（长连接）」+「微信插件」，不开腾讯 AI、不存业务数据在企微后台；可见范围只选你本人 1 人，且你已在手机新建专属企业微信实体，与公司全员账号彻底隔开；不套 OpenClaw/Hermes 等裸终端外壳。 |
| **2. 大模型隐私 + `密：` 零出网 + 防注入** | 阿里云百炼商业标准 API 默认不用于训练且全程加密；**不接公有云 LangSmith**（仅本地调试时可选经 Tailscale 回传私有 `agentic_observability_hub`）；消息带 **`密：`** 前缀在代码层硬拦截，**1 字节都不出给云端模型或外搜**；外部邮件均包裹 `[UNTRUSTED_EXTERNAL_DATA]` 隔离标签，物理无 Shell 工具防注入；脱敏外搜前置剥离客户名、代号与报价数字（支持 `EXTERNAL_SEARCH_ENABLED=false` 一键封闭）；System Prompt 不写死密钥、私有 URL 或核心商业底数。 |
| **3. Wissentek 世纪互联 `Sites.Selected` 隔离** | 严禁申请 `Files.ReadWrite.All` 或 `Sites.ReadWrite.All`；仅在 Wissentek 世纪互联建 **1 个仅本人可见的私有文档库** 并通过 `Sites.Selected` 只赋这 1 个库的写权，彻底碰不到公司其他员工文件。 |
| **4. 驾驶舱 Web 隐身访问 & 主机加固** | **驾驶舱网页默认绑定 `127.0.0.1` 与 Tailscale 加密内网网卡**，公网安全组**零入站端口暴露**（手机/Mac 连上 Tailscale 即可直接打开，外网黑客连端口都扫不到；若改走 Nginx HTTPS 反代则必须开强口令 + HttpOnly Cookie + 登录限流）。上线前轮换 `env/.env.bailian` 旧 Key，为 `firematrix` 改用专用 SSH Ed25519 密钥并禁用密码登录，`/etc/wechat-agent/env` 锁死 `640` 权限，日志禁用明文正文。 |
| **5. Git 与业务数据隔离** | GitHub 仅存纯代码、脱敏回归样例与文档；SQLite 与缓存永不进 Git，根仓库 `.gitignore` 锁死 `**/.env.*`、`*.key`、`*secret*`、`*token*`、`*.pdf`。 |
| **6. 物理阉割对外发信能力** | 邮箱只配 `Mail.Read`（或只读 IMAP），绝不配 `Mail.Send` 与 SMTP；机器人仅单聊本人，物理上绝无替你对外乱发信息的可能。 |

## 三、 前置实操配置手册（你手机与电脑上要做的两件事）

### 3.1 把你刚建好的企业微信机器人加进「个人微信」（6 步实操）

**不需要在电脑安装桌面版企业微信**，只需在电脑浏览器打开管理后台、拿手机扫两次码即可：

1. **登录网页后台**：电脑浏览器打开 <https://work.weixin.qq.com>，用你手机上刚新建好账号的**蓝色「企业微信 App」**扫码登录。
2. **确认开启 API 长连接模式**：进入左侧/顶部的 **「应用管理」→「智能机器人」**：
   - 点开你刚建的机器人（若手机端建的是普通问答机器人且不支持切模式，直接在网页点 **「创建机器人 → 切换到 API 模式创建」** 新建一个叫 `工作助理` 即可）；
   - **可见范围**：只勾选**你自己 1 个人**；
   - **接入方式**：选择 **「使用长连接（WebSocket）」**（不要选 URL 回调）；
   - 保存后复制页面生成的 **`BotID`** 和长连接 **`Secret`**（填入后文服务器配置，切勿发到群里或写进 Git）。
3. **打开微信插件二维码**：在同一个电脑网页后台顶部导航栏最右侧，点击 **「我的企业」** → 左侧菜单 **「微信插件」** → 页面往下拉找到 **「邀请关注」二维码**。
4. **用绿色「个人微信」扫码（关键步！）**：拿起手机打开日常用的 **绿色「个人微信」** → 右上角 `+` → **「扫一扫」** → 扫描电脑屏幕上的微信插件二维码 → 点击 **「关注」**。
5. **找到机器人并建联**：打开手机**个人微信**底部的 **「通讯录」→「我的企业及企业联系人」** → 点开你的企业名称 → 点进 **`工作助理`**，发一句“你好”（等后续阿里云服务启动后会自动回应；先发一句也是企微允许机器人主动给你推每日简报的前提）。
6. **置顶聊天**：回到个人微信聊天首页，长按该聊天窗口 → **「置顶该聊天」**。此后你平时无需打开企业微信 App。

### 3.2 配置 Wissentek 世纪互联版 Office 365 私有库与 `Sites.Selected`

1. **新建仅自己可见的私有库**：用你的 Wissentek 账号登录世纪互联 Office 365 / SharePoint 网页端，新建一个私有团队站点或文档库（建议命名为 `董事长幕僚归档库`，成员仅保留你自己 1 人，不加任何其他员工）。记下该站点的 `Site ID`（可通过 Graph `/sites/<sharepoint域名>:/sites/<站点名>` 查得）。
2. **在世纪互联 Entra 门户注册应用**：管理员登录 <https://entra.partner.microsoftonline.cn> → 「应用注册」→ 新建应用 `Wissentek-AI-Assistant`：
   - 记录 **租户 ID (`MS_TENANT_ID`)**、**应用程序 ID (`MS_CLIENT_ID`)**，并在「证书和密码」新建客户端密码 **`MS_CLIENT_SECRET`**；
   - 在「API 权限 → 添加权限 → Microsoft Graph → 应用程序权限」中仅勾选 **`Sites.Selected`**（第二阶段若同租户拉工作邮件，再按需增补只读权限 **`Mail.Read`**），点击 **「代表 Wissentek 授予管理员同意」**。
3. **精确赋权单个私有库**：由管理员用脚本向 `https://microsoftgraph.chinacloudapi.cn/v1.0/sites/{MS_SITE_ID}/permissions` 提交一条 `roles: ["write"]` 授权记录绑定到 `MS_CLIENT_ID`。
4. **绑定到你 Mac 的 Finder**：回到浏览器打开刚才新建的 `董事长幕僚归档库`，点上方工具栏 **「添加到 OneDrive 快捷方式」**（或「同步」）。Mac 上登录你的 Wissentek 世纪互联 OneDrive 客户端后，这个私有库就会自动同步到本地文件夹，用 Finder 和 Obsidian 直接打开即可。

## 四、 服务端环境变量模板 (`/etc/wechat-agent/env`)

部署在 `firematrix` 上的标准配置文件模板（真实凭据仅填在服务器本地，切勿进 Git 或文档）：

```ini
# --- 1. 运行基础 ---
TZ=Asia/Shanghai
DATA_DIR=/opt/wechat-agent/data
TMP_CACHE_DIR=/opt/wechat-agent/tmp_cache
LOG_LEVEL=INFO
DISK_ALERT_PERCENT=80

# --- 2. 微信通道（企业微信智能机器人长连接） ---
WECOM_BOT_ID=<第 3.1 步复制的 BotID>
WECOM_BOT_SECRET=<第 3.1 步复制的长连接 Secret>
SEGMENT_QUIET_SECONDS=60

# --- 3. 阿里云百炼三档异构模型（统一 OpenAI 兼容端点） ---
DASHSCOPE_API_KEY=<新生成的百炼专用 API Key>
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
FAST_MODEL=qwen3.8-flash
FAST_FALLBACK_MODEL=qwen-plus
PRODUCER_MODEL=qwen3.8-max
PRODUCER_FALLBACK_MODEL=qwen-max
CRITIC_MODEL=deepseek-v4-pro
CRITIC_FALLBACK_MODEL=qwen3.8-max
MAX_REFLECTION_LOOPS=2

# --- 4. Wissentek 世纪互联版 Office 365（已定稿锁定） ---
MS_CLOUD_ENV=china_21vianet
MS_AUTH_URL=https://login.chinacloudapi.cn
MS_GRAPH_URL=https://microsoftgraph.chinacloudapi.cn/v1.0
MS_TENANT_ID=<Wissentek 世纪互联租户 ID>
MS_CLIENT_ID=<Entra 应用 Client ID>
MS_CLIENT_SECRET=<Entra 应用 Client Secret>
MS_PERMISSION_MODE=sites_selected
MS_SITE_ID=<董事长幕僚归档库 Site ID>

# --- 5. 内嵌董事长项目管理驾驶舱 Web App ---
WEB_ENABLED=true
WEB_BIND_HOST=127.0.0.1               # 或 Tailscale 虚拟网卡内网 IP（严禁直接绑定 0.0.0.0 裸露公网）
WEB_PORT=8090
WEB_ACCESS_SECRET=<随机 32 位以上登录与签名密钥>
DAILY_CAPACITY_HOURS=6.0              # 每日董事长净工时预算红线（用于负荷热力图预警）

# --- 6. 工作邮箱自动拉取（第二阶段启用，物理只读） ---
MAIL_ENABLED=false
MAIL_PROVIDER=graph_mail              # graph_mail（同租户 Graph Mail.Read）或 imap
MAIL_POLL_INTERVAL_SECONDS=120
IMAP_HOST=<仅非 O365 邮箱走 IMAP 时填写>
IMAP_PORT=993
IMAP_USER=<工作邮箱>
IMAP_PASSWORD=<只读客户端授权码>

# --- 7. 可选：脱敏外部情报并发检索 & 私有观测 ---
EXTERNAL_SEARCH_ENABLED=false         # 设为 true 后允许脱敏技术调研
METASO_API_KEY=<可选>
SERPER_API_KEY=<可选>
JINA_API_KEY=<可选>
OBS_HUB_ENABLED=false                 # 仅调试期经 Tailscale 连本地私有观测中心时开启
OBS_HUB_URL=http://127.0.0.1:8765

# --- 8. 确认模式与每日简报 ---
CONFIRM_MODE=preview_card             # preview_card（回1确认）或 auto_with_undo（高把握自动+24h可撤销）
DAILY_MORNING_DIGEST=08:30
DAILY_EVENING_DIGEST=18:00
```

## 五、 三阶段实施路线与 Ch.19 自动化质量门禁

### 第一阶段：董事长助理 MVP + 驾驶舱核心版（3～5 天）
1. **安全与前置对接**：完成 `firematrix` SSH 加固与百炼 Key 轮换；按第 3 节完成企微长连接绑定个人微信，以及 Wissentek 世纪互联 `Sites.Selected` 私有库赋权。
2. **微信实测 T1–T3**：跑通纯 Python `websockets` 长连接，记录合并转发/逐条转发行为与发文件字数上限。
3. **内核、工时排期与驾驶舱上线**：上线 LangGraph 有界闭环、`qwen3.8-flash`/`qwen3.8-max`/`deepseek-v4-pro` 三档反思博弈、`密：` 物理拦截、三维工时排期预估与 `开始 N`/`完成 N 1.5h` 打卡、世纪互联 OneDrive 异步分片上传（含四大 `.md` 自动刷新）及同进程 FastAPI 驾驶舱网页（负荷热力图 + 精力占比 + 甘特周期 + 看板）。

### 第二阶段：工作邮箱自动接入 + 脱敏并发调研（第 2 周）
1. 开启 `MAIL_ENABLED=true`，接入只读邮件拉取 + `[UNTRUSTED_EXTERNAL_DATA]` 隔离包裹；
2. 补齐 PDF 按页提取、Office 与图片 OCR 全文入库 `sources_fts`（按需补轻量向量列实现混合检索）；
3. 按需开启 `EXTERNAL_SEARCH_ENABLED=true`，让语音想法自动附带脱敏公开技术调研简报写入 OneDrive。

### 第三阶段：Ch.19 三层质量门禁 + 日常自进化（第 3 周）
每次迭代提示词或切换模型前须通过三层门禁：
1. **确定性单测与护栏门禁**：数字保真 100%、净工时与日历周期分离测试、`assert_no_secrets_leaked`、Excel 逐行 Diff、脱敏过滤及 `before_tool_callback` 拦截；
2. **轨迹评估（`Trajectory Eval`）**：Mock 工具验证智能体是否按预期选择检索、排期校核或精算工具；
3. **`LLM-as-a-Judge` 黄金回归集**：对照 Rubric 评测切分、工时估算、冲突识别及带页码问答准确性，不退步才切换。
