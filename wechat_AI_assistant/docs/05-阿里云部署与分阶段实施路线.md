## 一、 阿里云单机部署边界（什么跑在 ECS，什么存在世纪互联 OneDrive）

整套软件采用「单机全包、网盘沉淀、零外部 ERP 依赖」拓扑：

- 运行在阿里云 ECS firematrix（呼和浩特，2 核 4G，Ubuntu 24.04，详见本地 env/.env.ecs）上的组件：
  1. 董事长助理智能体内核（微信客服 API + 自建应用 HTTPS 回调 + 只读邮件拉取 + LangGraph 有界闭环 + 百炼三档模型调用）；
  2. 同进程内嵌式「董事长项目管理与工时分析驾驶舱 Web App」（FastAPI + 静态 ECharts/甘特图前端）；
  3. SQLite 结构化数据库与全文检索索引（app.db 与 checkpoints.db，含所有任务、起止时间、净工时、项目状态和文档按页提取纯文本）。
  - 运行方式：以独立非特权系统用户 wxagent 跑 systemd 单实例后台服务（绑定 127.0.0.1:8090），由 Nginx 通过独立子域名 https://assistant.fire-matrix.com 反代，与机上已有 firematrix-web（端口 3000，www / wechat 域名）互不干扰。
- 主存于 Wissentek 世纪互联版企业 OneDrive 的内容（纯云端零本地占盘）：
  - 全部原始转发文件与邮件附件（00_原件收件箱/）、自动命名的分类文档库（01_项目归档～04_想法与行业参考）以及自动渲染的四大 Markdown 清单（00_我的四大清单/）。
  - ECS 与本机双端不爆满机制：大附件上传 Wissentek 世纪互联校验完成后自动清理 ECS 本地临时缓存，ECS 只保留纯文本索引；同时不在您本地 Mac 安装同步盘，所有历史文件与清单 100% 留存云端，通过浏览器网页端与驾驶舱直链在线浏览。

## 二、 企业核心信息防外泄「六道硬防线」

| 防线 | 核心举措 |
| :--- | :--- |
| 1. 入口与单人白名单隔离 | 采用已拍板的 方案 B：绿色个人微信置顶「微信客服 API」（代码硬锁 OWNER_EXTERNAL_USERID 单人白名单，非本人扫描请求直接静默丢弃）＋「自建应用（可见范围仅本人 1 人）+ 微信插件」；腾讯侧不开 AI、不存业务数据；不套 OpenClaw/Hermes 等裸终端外壳。 |
| 2. 大模型隐私 + 防注入 | 阿里云百炼商业标准 API 默认不用于训练且全程加密（复用 env/.env.bailian 多应用共用 Key，严禁改删）；不接公有云 LangSmith（仅本机开发调试时可选连 127.0.0.1:8765 私有 agentic_observability_hub，线上 ECS 默认关闭）；外部邮件均包裹 [UNTRUSTED_EXTERNAL_DATA] 隔离标签，物理无 Shell 工具防注入；脱敏外搜前置剥离客户名、代号与报价数字（支持 EXTERNAL_SEARCH_ENABLED=false 一键封闭）；System Prompt 不写死密钥、私有 URL 或核心商业底数。 |
| 3. Wissentek 世纪互联 Sites.Selected 隔离 | 严禁申请 Files.ReadWrite.All 或 Sites.ReadWrite.All；仅在 Wissentek 世纪互联建 1 个仅本人可见的私有文档库（chairman-vault） 并通过 Sites.Selected 只赋这 1 个库的写权，彻底碰不到公司其他员工文件。 |
| 4. 驾驶舱独立子域名 Nginx HTTPS & 主机加固 | Python 进程仅监听 127.0.0.1:8090（阿里云安全组零新增入站端口），由独立已备案子域名 https://assistant.fire-matrix.com（Nginx 443 + Let's Encrypt）统一承载驾驶舱与企微加密回调，固定驾驶舱链接 + 微信 6 位验证码登录 + HttpOnly; Secure; SameSite=Lax 180 天 Cookie + fail2ban 限流防爆破。为 firematrix 启用专用 Ed25519 SSH 密钥（保留原 root 登录兼容存量官网部署脚本），/etc/wechat-agent/env 锁死 root:wxagent 640 权限，日志禁用明文正文。 |
| 5. Git 与业务数据隔离 | GitHub 仅存纯代码、脱敏回归样例与文档；SQLite 与缓存永不进 Git，根仓库 .gitignore 锁死 **/.env.*、*.key、*secret*、*token*、*.pdf。 |
| 6. 物理阉割对外发信能力 | 邮箱只配 Mail.Read（或只读 IMAP），绝不配 Mail.Send 与 SMTP；微信客服与自建应用严格白名单锁死本人，物理上绝无替你对外乱发信息的可能。 |

## 三、 前置实操配置手册（你手机与电脑上要做的两件事）

### 3.1 企业微信绿色个人微信双口协同（✅ 方案 B 已拍板，后台路径实机已核查）

> 完整实测体检报告、中英文双语后台按钮对照与详细配置步骤见 [08-企业微信机器人设置核查与个人微信接入实操手册.md](08-企业微信机器人设置核查与个人微信接入实操手册.md)。

1. 已完成项目（✅ 已实机完成配置）：
   - 您已在专属企微组织完成个人微信扫 「我的企业 → 微信插件」 关注（状态 已关注，且已勾选允许收发消息）；
   - 已新建自建应用 工作助理（可见范围仅本人 1 人），通过 https://assistant.fire-matrix.com/api/wecom/app/callback 校验与 企业可信 IP 配置；并已在 应用管理 → 基础 → 微信客服 将 AI_assistant客服 绑定至 工作助理 统一接管（共用同一个回调与同一个 WECOM_APP_SECRET）。
2. 待从手机获取 1 项凭据：打开手机蓝色 「企业微信 App → 企业微信团队」，复制刚下发的 工作助理 Secret（WECOM_APP_SECRET）写入本地 [env/.env.wecom](file:///Users/john/Desktop/agentic_learning/wechat_AI_assistant/env/.env.wecom) 并锁定本人 OWNER_EXTERNAL_USERID 即可。

### 3.2 配置 Wissentek 世纪互联版 Office 365 私有库与 Sites.Selected（✅ 已全部实机完成）

> 完整实测菜单方位与按钮说明见 [07-世纪互联SharePoint私有库与OneDrive实操手册.md](07-世纪互联SharePoint私有库与OneDrive实操手册.md)。

1. 新建仅自己可见的私有库（✅ 已完成创建 chairman-vault）：登录 https://wissentek.sharepoint.cn 后，在最左侧纵向应用栏进入 「生成」→「开始构建」→「网站」→「团队站点」→「标准团队」→「使用模板」；在「设置站点」中新建私有站点 董事长幕僚归档库，群组与站点地址设为 chairman-vault（https://wissentek.sharepoint.cn/sites/chairman-vault），隐私选择 专用 - 仅成员可访问此站点 并跳过加人（成员仅保留你自己 1 人）。
2. 在世纪互联 Entra 门户注册应用（✅ 已完成 Wissentek-AI-Assistant 注册与隔离赋权）：经 https://portal.partner.microsoftonline.cn →「所有管理中心 → Microsoft Entra」进入实际可用的世纪互联 Entra 地址 https://entra.microsoftonline.cn/（entra.partner.microsoftonline.cn 已不可达）完成注册，仅保留 Sites.Selected 与只读 Mail.Read（临时初始化 Sites.FullControl.All 赋权 chairman-vault 后已彻底移除并撤销同意），物理禁止 Mail.Send 与全租户读写。
3. 纯云端快捷入口（✅ 已添加至网页版 OneDrive「我的文件」，不在 Mac 占本地盘）：已在站点 Documents 库点击 「Add shortcut to OneDrive」→「My files」，在网页版 OneDrive「我的文件」生成 董事长幕僚归档库 - Documents 云端快捷入口。按您的轻量化需求，不在本机 Mac 安装同步盘占用存储，需要翻阅原件时直接通过浏览器或驾驶舱直链在线打开。

## 四、 服务端环境变量模板 (/etc/wechat-agent/env)

部署在 firematrix 上的标准配置文件模板（真实凭据仅填在服务器本地，切勿进 Git 或文档）：

```ini
# --- 1. 运行基础 ---
TZ=Asia/Shanghai
DATA_DIR=/opt/wechat-agent/data
TMP_CACHE_DIR=/opt/wechat-agent/tmp_cache
LOG_LEVEL=INFO
DISK_ALERT_PERCENT=80

# --- 2. 微信通道（已拍板方案 B：自建应用「工作助理」统一承接微信客服 API + 微信插件） ---
WECOM_CORP_ID=<企业微信 CorpID>
WECOM_APP_AGENT_ID=<自建应用 工作助理 AgentId>
WECOM_APP_SECRET=<手机企业微信收到的 工作助理 Secret（共用驱动微信客服与简报推送）>
WECOM_APP_TOKEN=<接收消息回调 Token>
WECOM_APP_AES_KEY=<接收消息回调 EncodingAESKey>
WECOM_KF_OPEN_KFID=<AI_assistant客服 OpenKfId (wk...)>
OWNER_EXTERNAL_USERID=<本人个人微信扫码后的唯一 external_userid 白名单>
SEGMENT_QUIET_SECONDS=60

# --- 3. 阿里云百炼三档异构模型（统一 OpenAI 兼容端点） ---
DASHSCOPE_API_KEY=<直接复用 env/.env.bailian 现有共用 Key，严禁重置或删除>
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
FAST_MODEL=qwen3.8-flash
FAST_FALLBACK_MODEL=qwen-plus
PRODUCER_MODEL=qwen3.8-max
PRODUCER_FALLBACK_MODEL=qwen-max

CRITIC_FALLBACK_MODEL=qwen3.8-max

# --- 4. Wissentek 世纪互联版 Office 365（已定稿锁定，纯云端归档） ---
MS_CLOUD_ENV=china_21vianet
MS_AUTH_URL=https://login.partner.microsoftonline.cn
MS_GRAPH_URL=https://microsoftgraph.chinacloudapi.cn/v1.0
MS_TENANT_ID=<Wissentek 世纪互联租户 ID>
MS_CLIENT_ID=<Entra 应用 Client ID>

MS_PERMISSION_MODE=sites_selected
MS_SITE_ID=<董事长幕僚归档库 chairman-vault Site ID>

# --- 5. 内嵌董事长项目管理驾驶舱 Web App ---
WEB_ENABLED=true
WEB_BIND_HOST=127.0.0.1               # 仅监听本机回环端口，严禁绑定 0.0.0.0 裸露公网
WEB_PORT=8090
WEB_PUBLIC_BASE_URL=https://assistant.fire-matrix.com   # 独立已备案子域名 Nginx HTTPS 443 反代（微信内直开不拦截）
WEB_ACCESS_SECRET=<随机 32 位以上会话 Cookie 签名密钥>
WEB_SESSION_DAYS=30
DAILY_CAPACITY_HOURS=6.0              # 兼容保留，2026-11-18 起排期改按每日事项密度判断，不再使用

# --- 6. 工作邮箱自动拉取（第二阶段启用，物理只读） ---
MAIL_ENABLED=false
MAIL_PROVIDER=graph_mail              # graph_mail（同租户 Graph Mail.Read）或 imap
MAIL_POLL_INTERVAL_SECONDS=120
IMAP_HOST=<仅非 O365 邮箱走 IMAP 时填写>
IMAP_PORT=993
IMAP_USER=<工作邮箱>
IMAP_PASSWORD=<只读客户端授权码>

# --- 7. 可选：脱敏外部情报并发检索 & 私有观测 ---
EXTERNAL_SEARCH_ENABLED=false         # 设为 true 后允许脱敏技术调研
METASO_API_KEY=<可选>
SERPER_API_KEY=<可选>
JINA_API_KEY=<可选>
OBS_HUB_ENABLED=false                 # 仅本机开发调试连 127.0.0.1:8765 私有观测中心时开启，线上 ECS 默认关闭
OBS_HUB_URL=http://127.0.0.1:8765

# --- 8. 确认模式与每日简报 ---
CONFIRM_MODE=preview_card             # preview_card（回1确认）或 auto_with_undo（高把握自动+24h可撤销）
DAILY_MORNING_DIGEST=08:30
DAILY_EVENING_DIGEST=18:00
```

## 五、 三阶段实施路线与 Ch.19 自动化质量门禁

### 第一阶段：董事长助理 MVP + 驾驶舱核心版（3～5 天）
1. 安全与前置对接：保留现有百炼共用 Key；完成 assistant.fire-matrix.com 解析、firematrix SSH 加固与 HTTPS 签发；配置微信客服 API（锁死 OWNER_EXTERNAL_USERID）+ 自建应用 工作助理；完成 Wissentek 世纪互联 chairman-vault 私有库 Sites.Selected 赋权。
2. 微信实测 T0–T3：跑通 https://assistant.fire-matrix.com 下的微信客服与自建应用双口 HTTPS 回调，验证 merged_msg 合并转发拆包、逐条转发行为与媒体大小边界。
3. 内核、工时排期与驾驶舱上线：上线 LangGraph 有界闭环、qwen3.8-flash/qwen3.8-max/deepseek-v4-pro 三档反思博弈、密： 物理拦截、三维工时排期预估与 开始 N/完成 N 1.5h 打卡、世纪互联 OneDrive 异步分片上传（含四大 .md 自动刷新，纯云端不落本地盘）及同进程 FastAPI 驾驶舱网页（负荷热力图 + 精力占比 + 甘特周期 + 看板 + 云端文件直链）。

### 第二阶段：工作邮箱自动接入 + 脱敏并发调研（第 2 周）
1. 开启 MAIL_ENABLED=true，接入只读邮件拉取 + [UNTRUSTED_EXTERNAL_DATA] 隔离包裹；
2. 补齐 PDF 按页提取、Office 与图片 OCR 全文入库 sources_fts（按需补轻量向量列实现混合检索）；
3. 按需开启 EXTERNAL_SEARCH_ENABLED=true，让语音想法自动附带脱敏公开技术调研简报写入 OneDrive。

### 第三阶段：Ch.19 三层质量门禁 + 日常自进化（第 3 周）
每次迭代提示词或切换模型前须通过三层门禁：
1. 确定性单测与护栏门禁：数字保真 100%、净工时与日历周期分离测试、assert_no_secrets_leaked、Excel 逐行 Diff、脱敏过滤及 before_tool_callback 拦截；
2. 轨迹评估（Trajectory Eval）：Mock 工具验证智能体是否按预期选择检索、排期校核或精算工具；
3. LLM-as-a-Judge 黄金回归集：对照 Rubric 评测切分、工时估算、冲突识别及带页码问答准确性，不退步才切换。
