# 阶段一（过渡期）考勤审计系统功能与使用指南
## 目录: `attendance_audit_integration/stage_one/stage_one_functions.md`

## 1. 阶段一系统功能清单 (Feature List)

第一阶段考勤审计系统在不依赖蓝牙打卡盒子（BLT1）和联网门禁的前期下，实现以下 6 大核心审计功能：

### 1.1 日基础考勤对账
- **功能描述**：系统每日上午 09:00 提取昨日（T-1）企业微信打卡日志，与员工的请假审批、出差审批进行勾稽比对。
- **对账判定**：对无故缺卡、未经批准的外勤等行为自动判定为“漏打卡异常”，向员工发出预警邮件，并限制在 2 天内（T+2 申诉窗口）通过请假或补打卡进行纠正。

### 1.2 三维防作弊定位监测 (Anti-Cheating Detection)
- **企微设备异常检测**：读取企微 API 的 `exception_type` 字段，若检测到手机有 root/越狱、开启开发者虚拟位置、或使用模拟定位软件，直接标记为“设备/位置异常作弊”。
- **瞬移速度可行性校验**：自动计算同一员工相邻打卡记录的 GPS 距离和物理时间差。如果换算出的移动时速 $V > 350\text{ km/h}$（瞬移），判定为“虚拟定位作弊”。
* **网络出口 IP 审计**：检查打卡数据包中的公网出口 IP 段。若员工申报在客户现场，但打卡 IP 显示为家庭宽带或异地 VPN 代理，自动记入可疑审计日志。

### 1.3 强制相机打卡防御
- **配置实现**：在企业微信考勤规则后台开启“必须拍照”并勾选“仅限现场拍照，限制从相册选择”。员工日常拍照打卡、外出外勤打卡时强制调取原生摄像头，屏蔽本地相册。

### 1.4 出差日报后置复合审计
- **功能描述**：月度终审时，系统提取员工出差天数对应的《现场工作日报》提交情况。
- **审计规则**：如果出差某日缺失对应的日报（或日报内未拍照上传水印照片），判定为“出差异常离岗”，系统向员工发送警告，并抄送高管。

### 1.5 加班服务报告手写签字审计
- **功能描述**：员工周末加班工时，必须与客户现场代表签字的《现场服务报告》进行后置对账。
- **审计规则**：月度终审时，系统核对加班打卡记录与服务报告日期及工时。若缺失服务报告，或服务报告未经过客户手写签字确认（`is_customer_signed = FALSE`），系统将**拒绝生成该日的调休假余额**。

### 1.6 调休假流水管理 (Compensatory Leave Tracker)
- **功能描述**：对核销无误的普通周末加班工时记入 `compensatory_leave_details`。
- **功能特点**：支持调休余额的累加、消耗抵扣，并为 HR 呈现剩余可调休天数。

## 2. 员工（Employee）使用与申报指南

在第一阶段下，员工在日常考勤和出差申报时需遵循以下流程：

### 2.1 日常办公室打卡流程
1. 员工在上下班时，进入手机企业微信 -> “工作台” -> “打卡”。
2. 系统会自动调起手机原生摄像头。员工必须**实时自拍**完成拍照定位打卡（无法从相册上传照片，亦无法使用滤镜/美颜等可能被判定为虚拟设备的软件）。

### 2.2 考勤异常申诉与假单抵扣流程
1. 若昨日出现漏打卡，员工会在上午 09:00 收到系统自动发送的《考勤异常催告函》。
2. 员工必须在 **2 个工作日内（T+2）** 进行纠正：
   - **确属漏打卡**：在企业微信中发起“补卡申请（漏打卡补登）”，说明理由并等待主管和 HR 审批。
   - **请假抵扣**：在企业微信中发起请假审批，选择用“年假”或“调休（倒休）”折抵该异常时段。
   - **无假转事假**：若年假和调休余额已为 0，员工发起“事假”申请，系统按“无劳动无报酬”原则扣除当日/半日基本工资。
   - **拒不申报**：逾期不补办任何审批者，系统强制将该记录最终确认为“无故旷工 0.5 天/1.0 天”，并计入劳动纪律档案。

### 2.3 出差及现场加班申报流程
1. **出差期间**：每日下班前，必须在企业微信提交《现场工作日报》，详细填写今日工作摘要，并强制调用水印相机拍摄现场自拍。
2. **周末加班**：在加班前，必须前置通过企微提交“加班申请”并获得批准。加班结束后，必须让客户现场代表在纸质《现场服务报告》上**手写签字**并拍照，通过企业微信上传该签字服务报告照片作为对账凭证。

## 3. HR 与部门主管（Manager）操作指南

### 3.1 部门主管审批与监督职责
1. **审批补卡与假单**：主管需对员工提交的补卡申请理由进行真实性审核。
2. **监督考勤异动**：主管每日会收到系统抄送的部门考勤异常预警邮件，对于多次漏打卡或异常离岗的员工，需及时进行诫勉谈话。

### 3.2 HR 主管考勤复核与月度封账职责
1. **日异常复核**：HR 登录系统后台，查看被系统“防作弊算法”标记的虚拟定位和异常设备日志。
2. **月度终审对账**：
   - 每月 5 日，HR 运行月度审计引擎，系统会自动比对“打卡数据 vs 出差日报”、“加班打卡 vs 手写签字服务报告”。
   - 系统自动标出无日报的出差日、无签字报告的加班日。HR 针对这些争议账目进行人工确认，选择“通过”或“驳回并记为旷工/无效加班”。
3. **锁定归档**：确认无误后，HR 点击“月度封账”，结转本月扣薪数据及下月年假、调休假余额。封账后历史考勤数据不可篡改。
