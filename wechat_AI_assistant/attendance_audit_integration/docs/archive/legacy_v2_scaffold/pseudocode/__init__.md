# __init__.py 伪代码

## 本文件职责（一句话）
声明 `attendance_audit_integration` 包标识与版本号，无业务逻辑。

## 对应PRD功能
无直接业务功能（包元数据）；支撑运维可观测性中的版本识别（非功能 7.x / diagnostics）

## 依赖
- 调用：无
- 被调用：包导入时隐式加载；diagnostics 等可读取 `__version__`

## 伪代码

模块加载时:
    设置 __version__ = "0.1.0"

## 异常与边界（必填）
- 本文件无运行时异常路径；写「无」的原因：仅常量赋值，不触达外部 I/O
- 不向上抛业务异常
- 边界：版本号变更时须同步 pyproject.toml / diagnostics 健康检查回退逻辑

## 注意事项 / 坑
- 版本号是诊断包与 API 根路径展示的来源之一，改版本时同步两处，避免「代码写 0.1.0、包元数据写别的」
