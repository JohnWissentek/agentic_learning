## 1. 阶段二：目标系统软硬件补齐要求

在第二阶段（目标期），公司将全面补齐硬件设备并完成劳动规章制度的合法性建设，使考勤审计达到行业最高防作弊与合规标准：

### 1.1 硬件设备部署规范
1. **物理蓝牙信标（BLT1）**：
   - 采购 3 台企业微信官方定制蓝牙打卡盒子（BLT1），每台京东售价约 129-179 元。
   - 粘贴于办公室大门、侧门、后门的出入口内侧墙面，手机蓝牙感应考勤。
2. **刷卡门禁系统一体机系统（ZKTeco / 得力）**：
   - 采购 3 套支持企业微信直连的刷卡门禁系统一体机（如 ZKTeco ZK-T1 套装，含磁力锁/电源，单套售价约 1,299 元）。
   - 门禁机通过有线网线（RJ45接口）直接连接至办公室网络交换机 or 主路由器。
   - 关闭人脸识别识别方式，仅开启 IC 刷卡与密码验证。
3. **IC 卡物理唯一芯片 ID（UID）与即时挂失注销机制**：
   - **唯一卡号标识**：发放到员工手中的每张标准 IC 门禁卡内部芯片均有一个出厂硬编码且唯一的全球唯一芯片号（UID / Card Number）。
   - **微信后台解绑注销（安全防卫）**：若员工离职或卡片丢失，管理员无需在门禁机本地操作。只需登录企业微信管理后台（或手机端“工作台 -> 打卡 -> 设备管理 -> 成员卡号”），选择该员工并**一键清除/注销其绑定的卡号**。
   - **秒级同步失效**：企业微信云端（WeCom IoT Cloud）会通过办公室网络，在 **3 秒内** 向 3 台 ZKTeco 门禁机下发删除指令。门禁机本地白名单立刻抹除该卡号。自此，丢失的卡片刷卡时门禁机将语音报警“无效卡/未登记”，电磁锁绝不开启，从物理层面上 100% 杜绝安全隐患。
4. **Wi-Fi BSSID 配置**：
   - 提取 2 处办公地点的无线路由器 MAC 地址（BSSID），录入企业微信白名单。

### 1.2 企业微信考勤规则后台安全加锁限制 (Camera Restriction)
为了彻底切断使用本地相册虚假打卡的漏洞，除了表单控制外，必须在企业微信手机端及管理端后台开启以下强限制：
* **上下班与外勤必须拍照**：在企业微信打卡规则设置的打卡方式“更多设置”中，强制勾选 **“打卡必须拍照”**（未拍照无法提交签到）。
* **锁定仅限现场拍照（限制相册）**：强制勾选 **“仅限现场拍照（限制从相册选择照片）”**。系统会强制调用手机摄像头快门，禁止用户调取本地图库或通过多开助手上传虚假自拍背景。

### 1.3 法律管理合规前提
- 完成《考勤与劳动纪律管理办法（暂行）》的草拟。
- 依法履行民主协商讨论与公示发布程序，收集全员亲笔签字签署的制度送达回执。

## 2. 第二阶段：系统审计核心功能与对账逻辑

设备与制度补齐后，考勤中间件对账引擎将启用**三位一体交叉审计与自动化假单抵扣功能**：

### 2.1 三合一交叉审计机制 (Three-in-One Verification)
系统每日提取 Wi-Fi 连接日志、蓝牙信标检测记录与门禁进出刷卡时间戳进行三维比对：
* **防代刷卡审计**：比对【手机蓝牙/WiFi 离线时间】与【门禁卡出门刷卡时间】。若发现两者时间差大于 15 分钟，直接判定为“疑似代打卡/虚假在岗异常”，并上报警告。
* **防尾随出门审计**：若手机连接信号显示员工中午离开办公区（离线达 40 分钟以上），但在 11:30 - 13:30 窗口内**无任何出门和进门刷卡流水**，直接判定为“未刷卡尾随出入异常”，触发个人警报。
* **时段限定感应**：系统仅在考勤敏感窗口期（08:00-09:30、11:30-13:30、17:30-19:00）内探测蓝牙和 WiFi 状态，最大程度节省手机电量并消除员工对隐私泄露的抵触。

### 2.2 缺卡转假单抵扣与事假扣薪流程
* **限期催告**：系统发现异常后自动触发 T+2 日限期催办通知，要求员工补假。
* **假期折抵**：允许员工在企微中申请用个人“年假”或“调休假”折抵。
* **事假扣除**：若假期余额不足，员工须申请“事假”（Unpaid Leave），系统按“无劳动无报酬”原则，折算并扣除对应时段的日薪基本工资（扣款额 = `基本工资 ÷ 21.75 × 缺勤天数`），不执行任何惩罚性罚款。
* **无诉讼风险旷工解雇**：若催告后员工逾期不申请假单或无法合理解释，系统锁存该记录为“无故旷工”（半日缺卡计为旷工 0.5 天，全日缺卡计为旷工 1 天）。

## 3. 民主程序执行与法律合规保障指引 (Democratic Process Guidelines)

为了让第二阶段的惩戒和辞退规则（**单月旷工达 3 天，或全年旷工达 5 天无偿辞退**）在面临劳动争议仲裁时 100% 获得司法支持，必须严格执行以下民主与公示步骤：

```
  1. 草拟考勤办法  ──►  2. 召开职工讨论会议  ──►  3. 协商修改定稿
                                                       │
                                                       ▼
  5. 收集全员签字确认回执  ◄──  4. 正式公示并上线系统  ◄──  协商记录证据固化
```

1. **草拟制度（Drafting）**：
   - 细化《考勤与劳动纪律管理办法（暂行）》，写明“四选一打卡”、“T+2催补假窗口”、“无假期转事假扣除对应日薪”、“旷工0.5天判定”及“严重违纪无补偿解除合同界限”。
2. **召开民主讨论会议（Democratic Discussion）**：
   - 召开全体员工会议，宣讲并讨论该管理办法。
   - **务必保留并固化协商讨论的会议纪要、会议拍照、以及收集员工意见的记录**（这是劳动仲裁中证明履行了《劳动合同法》第四条民主协商程序的核心证据）。
3. **协商定稿与公示（协商与公示）**：
   - 与员工协商确定最终定稿，在公司物理公告栏及企业微信群中公示发布。
4. **送达确认（Signed Receipt - 决定成败的一步）**：
   - 必须让每一位员工在一份纸质的《规章制度知悉与送达确认书》上**亲笔签字**。
   - **司法判定红线**：没有员工亲笔签名确认的送达文件，一旦进入司法仲裁，该规章制度将无法作为对该员工进行处罚 and 辞退的合法依据。
