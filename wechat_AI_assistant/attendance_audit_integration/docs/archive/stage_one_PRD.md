# 产品需求文档 (PRD) - 阶段一（过渡期方案）
## 目录: `attendance_audit_integration/stage_one/docs/PRD.md`

## 1. 产品概述（阶段一）

### 1.1 目的
在第一阶段（过渡期），公司考勤系统在**无蓝牙打卡设备、无联网门禁及未修改《员工手册》的现状下**实施考勤审计。本阶段将最大化利用企业微信现有的数据源，结合员工日常提交的**《现场工作日报》**、**《现场服务报告》**以及**调休假流水明细**，实现基础考勤勾稽与后置复合审计，并自动向考勤异常的员工发送提醒邮件，同时向公司管理层发送每日/每周/每月考勤报表。

### 1.2 第一阶段打卡方式与安全加锁
* **拍照打卡限制**：强制在企业微信后台开启“必须拍照打卡”且“仅限现场拍照（限制相册）”的防作弊设置。员工打卡时必须实时使用手机摄像头拍照，杜绝相册图片上传。
* **虚拟定位技术监测**：利用企业微信原生防作弊字段与后端引擎的“速度与网络比对算法”来检测虚拟定位。

## 2. 考勤匹配规则与审计逻辑（阶段一）

### 2.1 办公室在岗打卡（四选一）
员工在办公区只需完成以下打卡途径之一：
1. **Wi-Fi 自动打卡**（连接公司办公室网络）。
2. **手机 GPS 定位打卡**。
3. **手机拍照定位打卡**（强制仅限原生相机实时对焦自拍）。
4. **门禁刷卡打卡**（仅限不联网门禁，数据只在本地，需在手机企微补打卡登记）。

### 2.2 差旅及外出人员考勤（双重打卡选择）
1. **外勤 GPS 手动打卡**：员工在现场通过手机自拍外勤打卡（阶段一暂无 100m 电子围栏校对）。
2. **现场工作日报（每日照片水印）**：员工在出差期间，每日必须提交企业微信中的**《现场工作日报》**。

### 2.3 后置复合凭证交叉审计（阶段一已启用）
月度审计时，系统拉取以下后置业务凭证进行强制交叉核验：
* **出差日报审计**：核对出差期间是否每日提交了《现场工作日报》且附有水印工作照。
* **加班服务报告审计**：周末加班必须上传带有客户现场代表手写签字的《现场服务报告》以及包含现场办公室环境的水印照片，否则该日加班不计入调休余额。
* **调休假流水管理**：系统对合格的周末加班工时计入 `compensatory_leave_details`（调休明细表），并监控其累积及使用状态。

## 3. 虚拟定位防作弊检测技术手段 (Anti-Cheating Methods)

为了防止员工使用虚拟定位软件，阶段一考勤审计引擎在后端集成了三种检测技术手段：

```
  ┌────────────────────────────────────────────────────────┐
  │           【阶段一：虚拟定位三维监测技术手段】          │
  └────────────────────────────────────────────────────────┘
     ▼                                ▼                                ▼
  【企微防作弊状态检测】            【逻辑速度可行性校验】           【网络出口 IP 审计】
  直接提取企微接口返回的            比对同一人相邻打卡点距离          核对打卡时的 IP 地址是
  “打卡异常/位置异常”状态。         与物理时间差，识别瞬移。         否属于家庭宽带或代理。
```

1. **企业微信原生防作弊状态读取**：
   - 企微打卡 API 返回的打卡记录中，包含了 `exception_type`（打卡异常类型）字段。
   - 如果员工手机使用了越狱/ROOT 工具、模拟定位助手或开发者选项中的“模拟位置”，企业微信安全引擎会自动将其标记为“设备异常”或“位置异常”。本系统会直接拦截这些被企微标记的异常数据，并将 `is_anomaly` 记为 `TRUE`，异常理由记录为 *"企业微信系统判定设备/位置异常作弊"*。
2. **物理速度与空间可行性校验（Speed Feasibility Check）**：
   - 系统引擎在分析员工的相邻打卡点时，自动计算距离与物理时间差。
   - *例如*：如果员工 09:00 在北京办公室拍照打卡，10:00 在上海客户现场进行了外勤打卡，两地距离与时间差换算出的移动速度远超物理极限，系统会自动判定为“虚拟定位空间矛盾作弊”。
3. **网络出口 IP 段审计 (Network IP Auditing)**：
   - 系统核对打卡数据包中的网络 IP 地址段。若员工申报在客户现场，但打卡 IP 显示为家庭宽带或异地 VPN 代理 IP，则系统会将其列入可疑名单并生成预警。

## 4. 第一阶段系统缺陷与管理风险漏洞

* **代拍照打卡中转漏洞**：由于无门口蓝牙（BLT1）和 WiFi BSSID 精准绑定，员工虽不能从相册选照片，但可以把账号交给同事，由现场同事代为拍照打卡。
* **合规惩戒法律盲区**：由于尚未走民主程序，本阶段**不能**直接扣减基本工资或直接开除缺卡员工，所有扣薪（转事假）和违纪警告必须由 HR 人工通知后手动流转。
