## 1. 阶段一：现行条件与软硬件现状

在第一阶段（过渡期），公司考勤硬件及制度尚未完成改造，现行物理与管理条件如下：
* **门禁系统**：仅有传统的线下独立门禁锁（员工钥匙或独立不连网的磁卡），门禁进出流水**无法同步到企业微信，亦无法供考勤系统拉取**。
* **蓝牙设备**：办公室大门及通道尚未部署企业微信蓝牙打卡器（BLT1），手机无法通过蓝牙低功耗广播（BLE）进行无感测温打卡。
* **WiFi 网络**：已连接公司路由器 Wi-Fi，但 Wi-Fi 节点的 BSSID（MAC 地址）白名单尚未在企业微信后台完成高精度对齐。
* **外出与出差（打卡无 GPS 围栏）**：外勤及出差人员**完全没有 GPS 地理围栏定位校对**，仅依靠员工在手机企业微信内进行基础的手动外勤打卡（没有目的地经纬度核对）。
* **出差日报**：员工出差提交现有的《现场工作日报》，但该日报中“现场环境水印照片”的上传在企业微信内**非强制必填项**，且未限制必须使用实时相机拍照。
* **劳动纪律制度**：尚未启动针对“多渠道打卡限制”、“未刷卡尾随离岗判定”以及“单月缺卡3次开除”的民主沟通协商会议，现行《员工手册》不支持强制扣发工资或以此无补偿辞退。

## 2. 阶段一：系统审计实施范围与算法逻辑

在现有条件下，考勤集成审计中间件将最大化利用企业微信现有的数据源进行过渡期审计：

### 2.1 基础勾稽审计与防作弊策略 (T-1 日对账)
* **打卡手段与相机强限制（防假图）**：
  - 员工通过企业微信的**“手机拍照打卡 / 手机定位打卡（GPS）”**。
  - **强制开启“仅限现场拍照，限制从相册选择”配置**：管理员在企业微信打卡规则后台，勾选“必须拍照”并强制启用“仅限现场拍照”选项。这会屏蔽员工上传本地相册图片的权限，调起手机自带原生相机进行实时拍摄。
* **审计逻辑**：
  - 后端引擎每日提取昨日（T-1）企业微信中员工的原始打卡日志 `attendance_logs`（获取首次上班打卡和末次下班打卡的时间与位置坐标）。
  - 对比昨日的审批列表 `approvals`（请假、出差）。
  - 若在正常工作日内缺失任何一侧打卡，且没有关联的请假或出差审批，系统将其标记为 **“考勤缺卡异常”**。
* **预警提醒**：系统每日向缺卡员工发送提示邮件，要求其通过企业微信向主管申请“补打卡（漏打卡补登）”，以便主管进行人工确认。

### 2.2 出差日志关联审计 (M-1 月对账)
* **审计逻辑**：
  - 月度终审时，系统提取员工出差天数对应的《现场工作日报》提交次数。
  - 若员工在该日处于“出差（Business Trip）”状态，但未能在企业微信中提交《现场工作日报》，系统生成差旅对账警告，要求员工补交日报作为出差在岗证明，否则可能阻断出差津贴核发。

## 3. 阶段一：考勤制度缺陷与技术安全漏洞清单 (Gaps & Vulnerabilities)

第一阶段作为过渡期方案，在技术防作弊和法律合规上存在显著缺口。公司管理层应对以下漏洞保持知情：

```
  ┌────────────────────────────────────────────────────────┐
  │              【阶段一：技术与管理三大漏洞】             │
  └────────────────────────────────────────────────────────┘
     ▼                                ▼                                ▼
  【漏洞 1：定位模拟作弊】          【漏洞 2：代自拍/代打卡】        【漏洞 3：合规惩戒盲区】
  使用 GPS 模拟器篡改手机          同事间分享微信账号，或分        缺乏民主公示程序，无法依
  坐标，可在任意地点打卡。          享自拍图片，规避打卡约束。       据缺卡记录依法开除员工。
```

### 3.1 技术漏洞 1：虚拟定位与外勤作弊无法防范 (Location Cheating)
* **技术原理**：由于现行方式完全依赖手机的 GPS 定位打卡，且外出/出差**无 GPS 地理围栏校对**，员工可轻易通过手机越狱/ROOT、安装“分身大师”、“GPS 模拟器”等软件，篡改手机向企业微信上报的地理位置。
* **后果**：员工即使在家睡觉，也能通过虚拟定位在手机上完成“出差现场签到”或“外勤客户拜访打卡”，第一阶段系统在技术上无法识破此类纯软件定位作弊。

### 3.2 技术漏洞 2：设备指纹与异地代自拍漏洞 (Buddy Punching)
* **技术原理**：虽然企业微信打卡被设定为“仅限现场拍照，限制使用相册”，封堵了上传相册旧照的漏洞。但如果公司没有绑定办公室物理设备（如蓝牙、本地 WiFi 硬件）：
  - 员工仍然可以与同事私下互换企业微信账号，由现场的同事使用真实相机在办公室背景下自拍打卡，系统无法在后台自动检测出账号是否为本人手机持有。

### 3.3 法律合规漏洞：无法执行严肃纪律处分 (Legal Enforcement Void)
* **违规辞退风险**：由于《考勤与劳动纪律管理办法》和零借口惩戒规则尚未经过《劳动合同法》第四条规定的“职工代表大会讨论、平等协商”等民主程序，且没有全员亲笔签字送达确认。
* **后果**：在此阶段，若公司根据系统记录的缺卡次数直接扣除员工薪资，或以“旷工达 3 天”为由单方面解雇员工，**将被劳动仲裁委员会判定为“违法克扣工资”和“违法解除劳动合同”**，公司将面临向员工支付双倍经济赔偿金的法律处罚。
