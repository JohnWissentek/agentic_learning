# 光纤光栅刻蚀自建产线（CAPEX 固定资产投资）vs 外购预刻蚀成品光纤决策分析

针对您的核心问题：**“光纤刻蚀是自己能做吗？如果自己做需要买什么专用设备、投资是多少？还是买来的光纤就要预先做好的？”**

直接给出行业实操结论：
1. **绝大多数做电厂锅炉测温系统的工程公司/设备商（90% 以上），都是直接买“预先刻蚀好（甚至连不锈钢毛细管都已经穿好）”的成品光栅串！** 只需把图纸（比如：总长 $45\text{ 米}$、每隔 $1.2\text{ 米}$ 刻一个点、工作温度 $550^\circ\text{C}$、各点波长按表格排布）发给上游光栅厂，上游按条定制交货。
2. **光栅刻蚀完全可以自己买设备做（没有卡脖子禁运）**，但不同工艺路线的设备投资差距极大（从 **65 万元** 到 **1,500 万元** 不等）。**只有当您每年稳定出货超过 $15,000\sim 30,000$ 个高温测温点（相当于每年做 $20\sim 40$ 台大型电站锅炉改造）时，自己买激光器刻蚀才划算**。

## 1. 三种光栅刻蚀方式：哪些能自己做？哪些只能买现成的？

| 刻蚀工艺路线 | **能不能自己买设备做？** | 原因与行业真相 |
| :--- | :--- | :--- |
| **路线一：飞秒激光直写/掩模刻蚀（耐 $800^\circ\text{C}\sim 1000^\circ\text{C}$）** | **✅ 完全可以自己做（最推荐自建的路线）** | 买的原材料是成盘的“普通耐高温聚酰亚胺（PI）涂覆光纤（约 $5\text{ 元/米}$）”。在自己洁净室里用**飞秒激光器透过涂覆层直接打光刻蚀**，不用剥皮、不用高压氢气罐，1 名熟练工程师即可操作。 |
| **路线二：紫外准分子激光刻蚀 + 高温退火再生（`RFBG`，耐 $750^\circ\text{C}$）** | **⚠️ 可以自己做，但环评安评麻烦** | 需要建设**$15\text{ MPa}$（150 个大气压）高压纯氢气载氢防爆间**，且准分子激光器需定期充装剧毒的**氟气（$\text{F}_2$）/ 氟化氪（$\text{KrF}$）混合气瓶**，普通写字楼/园区很难批下危化品与防爆资质。 |
| **路线三：拉丝塔在线刻写超弱光栅阵列（`DTG / UWFBG`）** | **❌ 绝对不能自己做，必须买预先刻好的成品光纤！** | 因为它是在 **$15\sim 25\text{ 米}$ 高的 $2000^\circ\text{C}$ 石墨光纤拉丝塔** 把石英棒拉成丝的那一瞬间在线打激光刻进去的！建一座特种光纤拉丝塔连厂房要 **2,000万～5,000万元**，只有长飞、理工光科、烽火、德国 FBGS 这种光纤原厂才能干。 |

## 3. 备选低门槛路线：如果自己做“紫外激光 + 高温热再生光栅（RFBG）”要投多少钱？

如果不用飞秒激光，而是走传统的**“紫外激光刻种子光栅 + $900^\circ\text{C}$ 管式炉热再生”**路线：
1. **紫外激光器**：美国 Coherent（相干）`BraggStar` / `COMPex` $248\text{ nm}/193\text{ nm}$ 准分子激光器（全新进口约 $90\sim 160\text{ 万}$；国内翻新二手准分子激光器或国产 $213\text{ nm}/266\text{ nm}$ 全固态深紫外激光器约 **$18\sim 35\text{ 万}$**）；
2. **高压载氢罐系统**：$15\text{ MPa}$ 不锈钢高压载氢反应釜 + 氢气报警与排风防爆柜（约 **$3\sim 5\text{ 万}$**）；
3. **剥皮机、涂覆机与掩模板**：光纤热剥机 + 聚酰亚胺二次涂覆机（国産约 **$6\sim 10\text{ 万}$**）+ 20 块紫外相位掩模板（国产筱晓光子等约 $4,000\text{ 元/块} \times 20 = 8\text{ 万}$）；
4. **高温再生管式炉与监控解调仪**：约 **$8\text{ 万}$**。
* **紫外热再生路线总投资**：约 **`45 万 ～ 70 万元`**（用国产深紫外或二手准分子）。但因为**每次载氢要泡 10 天氢气、每刻一个点都要剥皮再涂覆（机械强度低、人工慢）**，现在新建产线已普遍转向上面的**飞秒激光免剥皮直写路线**。

### 💡 最终实操落地建议（三步走策略）：
1. **第一阶段（前 1～10 个电厂项目）**：**100% 采购预先刻蚀并穿好 `316L` 不锈钢毛细管的成品传感光缆！**
   * 您只需要自己找机加工厂做**水冷壁焊接金属导热铁块（$12\text{ 元/块}$）**，并把精力集中在**解调主机算法、电厂 `DCS` 三维温度场软件以及现场锅炉焊接安装工艺**上。
2. **第二阶段（年出货稳定在 10～20 台锅炉）**：**先自研/组装“解调主机（Interrogator）”**。
   * 因为自研解调主机不需要买百万元的激光加工机床，只需要采购现成的光源模块、光电管和自己画一块 `ADC+FPGA` 电路板，就能把一台主机的成本从外购的 $8\sim 12\text{ 万元}$ 降到 **$2.4\sim 2.8\text{ 万元}$**，立竿见影省下大笔利润。
3. **第三阶段（年出货超过 25 台锅炉、年用光栅 $>20,000$ 点）**：再投资 **80～100 万元** 采购一套国产飞秒激光自动刻写台，买长飞的成盘聚酰亚胺光纤自己刻蚀，实现全产业链通吃。
